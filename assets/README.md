# Batman footer animation

Source: https://tenor.com/view/batman-pixel-art-pixel-gifs-batman-running-running-gif-19817783
Original GIF: https://media.tenor.com/--AQwe1rA8EAAAAj/batman-pixel-art.gif

The original six transparent running poses are preserved. `build_batman.py` scales them with nearest-neighbor sampling and moves the character across an 800 × 92 transparent strip. The output loops every six seconds. Source attribution is not a claim of ownership or a license grant.

Rebuild with Python and Pillow: `python assets/build_batman.py`.
